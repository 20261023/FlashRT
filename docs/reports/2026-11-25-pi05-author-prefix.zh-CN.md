# π0.5 固定输入回归与首个偏离层

## 双门复算

作业 `360012` 在同卡上测量固定 OpenPI 作者 E10、FlashRT BF16 E10、E8 和 E10 复测。作者 E10 中位数为 59.4 ms。每个项目点和作者各有 40 个动作样本，按请求 ID 配对到原四组输入。控制器校验了作者与 worker 的作业、GPU、workload 摘要、每组产物哈希；从 NPZ 逐次抽取 50 步、前 7 个有效通道重算。比较使用模型归一化输出，项目取 `raw_actions`，作者取 policy 的原始模型输出。checkpoint 的 MEAN_STD 后处理只作用于另一个公开返回字段。

| FlashRT | 中位数 ms | 对项目最坏 L2 / 最低 cosine | 对作者最坏 L2 / 最低 cosine | 结论 |
|---|---:|---:|---:|---|
| E10 | 41.9 | 0.000000 / 1.000000 | 1.658008 / −0.397237 | 作者门失败 |
| E8 | 38.4 | 0.036150 / 0.999482 | 1.650275 / −0.407734 | 作者门失败 |
| E10 复测 | 41.9 | 0.013640 / 0.999911 | 1.662127 / −0.394989 | 作者门失败 |

三点阶段归因均覆盖诊断 wall 的 99% 以上。E10 的独立 profile 中前缀为 19.0 ms，动作迭代为 17.0 ms，视觉为 5.6 ms。四个请求保留同一 prompt 和 state，两个只改变显式初始噪声，一个只调整图像亮度。两个实现都使用三个 RGB 视图，按原顺序送入视觉编码器，输入缩放到 [−1, 1]。项目将固定初始噪声转为 BF16，作者模型收到原始 FP32 噪声。两侧绑定的工作载荷摘要相同。

对这份冻结参考，还可以直接判断两道 L2 门能否同时满足。设同一次请求的作者和项目 public7 数组为 A、B。候选同时通过要求两者距离至多为 0.05 × (‖A‖ + ‖B‖)。逐次对齐 40 个保存样本，实测 ‖A−B‖ 是这个上限的 4.07–16.72 倍。即使找到全部偏差来源并使输出贴近作者，沿用该作业的原项目基线仍无法选出双门 winner。后续配对能量化分词修正的影响，决定仍按冻结的参考和阈值落账。

## 分词差异

在原作业的 Python 环境和固定源码上，实际执行 host 分词，使用原请求的 8 维 state。项目选择 SentencePiece 回退路径，补到 32 维后产生 143 个 token。固定 OpenPI `dd5c5ca9` 的 ModelTransformFactory 先执行 TokenizePrompt 再执行 PadStatesAndActions，实际产生 47 个有效 token。使用同一作者 tokenizer，将 state 预补到 32 维的对照得到 143 个 token。分词差异已实测，其对动作误差的贡献仍须同卡单变量实验确认。两道原门槛继续使用 L2 ≤ 0.05、cosine ≥ 0.999。

## W8A8 首偏离

作业 `359958` 的观测版源码为 `7346d21e`。从四个请求保存的 `uint16` BF16 位模式还原浮点数，重新比较 BF16 和 encoder W8A8。第 0 层 encoder 输入完全相同，归一化输出所保存的 9 行也相同。紧接的 QKV 投影保留了完整 911 × 2560 输出，原图及两个噪声对照的 relative L2 为 0.104543，cosine 为 0.994558；亮度对照为 0.104493 和 0.994563。局部 oracle 在原请求的九个位置显示，W8A8 实现与按其量化规则计算的 FP64 乘积再舍入 BF16 完全一致。单独量化激活的 relative L2 为 0.096181，单独量化权重为 0.019978。首个偏差主要来自激活量化。

|---|---:|---:|
| 原请求 | 0.323628 | 0.946313 |
| 噪声对照一 | 0.293926 | 0.957288 |
| 噪声对照二 | 0.253904 | 0.969640 |

同一模式下四个请求的 graph 和观测版 eager 保存数组逐元素相同。现有 W8A8 方案四例均失败，保留 NR，不再沿该量化方式追查舍入细节。针对作者差异的后续实验使用 BF16。
