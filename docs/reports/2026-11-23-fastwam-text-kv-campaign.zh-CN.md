# FastWAM 请求内文本 K/V 缓存实测记录

作业 `357202` 尝试在 A800 上使用当前已选的 BF16、Euler20、H32、预计算 T5、compiled prefill 和 denoise 配置比较文本 K/V 缓存。计划覆盖八个固定输入，按未缓存基线、缓存候选和基线复测顺序执行。

未开启缓存的基线 worker 返回 `-11`（SIGSEGV），没有生成计时或动作结果。最后一次诊断栈记录了 Inductor 编译线程和 SymPy 调用，无法据此确定触发段错误的具体指令。batch 在基线失败后停止，缓存候选和末尾复测均未启动。本轮三个配置点的延迟与质量均为 NR。

## 作业 357482 的两组对照

作业 `357482` 在同一张 A800 上自然完成。常规 Torch 和 compiled 各运行未缓存首测、缓存候选和未缓存复测。每个配置覆盖八个固定输入，每个输入正式计时三次，共 144 次。两组均使用 BF16、Euler20、H32、已准备的 T5 上下文，完整 CPU 动作形状为 `[1,32,7]`。compiled 组使用此前运行过的编译缓存的私有副本，首次加载、编译及预热在稳态样本之外。
